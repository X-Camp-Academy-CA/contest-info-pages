Date: Saturday, May 2, 2026 — in-person at TJHSST (Fairfax, VA) + online mirror

📊 Difficulty Overview
PRE-BRONZE Warm-up (A–B)
Count duplicate 2-char patterns in a string & repeatedly halve a cookie’s area. Pure implementation, no algorithm needed.
Take first: 101P 102P
BRONZE Entry (C)
Number theory: check if every divisor of n can be paired via GCD/LCM constraints. Clean math + divisibility reasoning.
Take first: 200 201
SILVER Intermediate (D–E)
Pirate game theory with greedy voting strategy. Minimize hills & valleys by modifying one elevation in a path.
Take first: 300 301
GOLD Advanced (F–H)
Reconstruct a tree from a distance matrix. Caterpillar reachability on a tree. Lexicographic sorting with coprime swap constraints.
Take first: 302 400H 501
PLATINUM Expert (I)
Navigate a dungeon with teleporters & label modifications; find shortest path across multiple queries using Dijkstra/BFS.
Take first: 400H 500H 502
PLATINUM+ Elite (J)
Compute product of LCMs over all contiguous subarrays mod 109+7. Advanced number theory & combinatorial optimization.
Take first: 602H 603H

💡 How to Prepare — By Your Current X-Camp Level
In CS101P / CS102P (Python foundations)?
  • Target problems A–B (Pre-Bronze). Solving them is a great achievement!
  • Problem C (Number Travelling) is a nice stretch goal — requires basic divisibility thinking.
In CS200 / CS201 / CS202 (Recursion, DFS, BFS)?
  • Aim for problems A–C. Problem C uses GCD/LCM — preview number theory concepts.
  • Problem D (Treasure / game theory) is a stretch goal after finishing CS201.
In CS300 / CS301 / CS302 (Silver-level algorithms)?
  • Target problems A–E solidly. D (game theory) and E (elevation optimization) are prime Silver problems.
  • Problem G (Caterpillar) is accessible after finishing CS302 — direct tree DFS application!
In CS400H / CS401H / CS501 (Gold-level prep)?
  • Aim for A–H. Problem F (tree from distances) directly uses CS302 + CS400H graph skills.
  • Problem H (coprime sorting) combines CS400H greedy + CS501 number theory.
In CS500H / CS502 (Platinum track)?
  • Push for A–I. Problem I (Cookie Dungeon) = advanced shortest path + data structures.
  • Problem J requires techniques from CS602/603 — keep it as a long-term goal.
In CS602 / CS603 (US Camp / USACO Platinum)?
  • All 10 problems are fair game. Problem J (LCM-array) is your battleground.
  • Placing at the top of the overall leaderboard is a realistic goal.
