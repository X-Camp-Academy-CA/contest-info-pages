📊 Difficulty Overview
PRE-BRONZE Warm-up (P1–P2)
Sort 3 numbers & check parity. Pure implementation, no algorithm needed.
Take first: 101P 102P
BRONZE Entry (P3–P4)
Digit rotation with reversal. GCD-based counting. Clean math + implementation.
Take first: 200 201
SILVER Intermediate (P5–P7)
XOR partition counting, permutation fixed-point simulation, tree diameter via DFS.
Take first: 300 301 302
GOLD Advanced (P8–P9)
Game theory + Sieve of Eratosthenes. Miller–Rabin primality for large numbers.
Take first: 400 501 502H
PLATINUM Expert (P10–P13)
Parallel binary search + seg tree, modular linear algebra, advanced DP recurrences.
Take first: 500 501 401 502H
PLATINUM+ Elite (P14–P16)
DP + NTT/FFT convolution. Advanced graph & combinatorics beyond USACO Platinum.
Take first: 602H 603H

💡 How to Prepare — By Your Current X-Camp Level
In CS101P / CS102P (Python foundations)?
  • Target problems 1–2 (Pre-Bronze). Solving them is a great achievement!
  • P3 (Card Game) is a nice stretch goal — pure list manipulation.
In CS200 / CS201 / CS202 (Recursion, DFS, BFS)?
  • Aim for problems 1–4. P4 needs GCD (preview it in CS501's number theory).
  • P7 (Forest / tree diameter) is accessible after finishing CS202.
In CS300 / CS301 / CS302 (Silver-level algorithms)?
  • Target problems 1–7 solidly. P5–P6 (XOR, permutation simulation) are prime Silver problems.
  • P7 (Forest) uses CS302 tree diameter — a direct application!
In CS400 / CS401 / CS402 / CS501 (Gold-level prep)?
  • Aim for 1–9. P8 (Ross Easy) directly uses CS400 greedy + CS501 prime sieve.
  • P9 (Ross Hard) adds Miller-Rabin — a great CS501 stretch goal.
In CS500 / CS502H (Platinum track)?
  • Push for 1–13. P10 (Bay) = seg tree + parallel binary search; P11–13 = advanced DP & math.
  • Problems 14–16 require techniques from CS602/603 — keep them as long-term goals.
In CS602 / CS603 (US Camp / USACO Platinum)?
  • All 16 problems are fair game. P14–16 (NTT, elite graph/combinatorics) are your battleground.
  • Placing at the top of the overall leaderboard is a realistic goal.

📌 Note on Difficulty Levels: The USACO equivalent ratings shown in the table below are cumulative — each level builds on all previous ones. For example, a problem rated Silver assumes you are already comfortable with Bronze-level skills (loops, arrays, basic math), and a Gold problem assumes both Bronze and Silver knowledge. Students should aim to fully master earlier levels before attempting harder problems.
